About

I'm Mayank Gupta, an Azure Integration Specialist with 7+ years designing and delivering enterprise-scale, event-driven solutions on Microsoft Azure using .NET, Node.js, Python and REST APIs — specialising in Azure Functions, Logic Apps, Service Bus, API Management and CI/CD with Azure DevOps.

Most of my work makes Dynamics 365, on-premise systems and third-party platforms talk to each other securely and reliably. Alongside that I've delivered full-stack application work — an Optimizely CMS platform in TypeScript and native iOS development for a Canada-based client. Lately the focus has moved to GenAI and agentic AI — RAG solutions, Azure OpenAI, Microsoft Foundry multi-agent systems and MCP servers.

  • Event-driven Azure integration — Functions, Logic Apps, Service Bus, APIM
  • Zero-trust security with Managed Identity, Entra ID and Key Vault
  • Resilience patterns — retry, circuit breaker, dead-letter, replay
  • Agentic AI on Microsoft Foundry, Azure OpenAI and MCP servers
  • Full-stack app delivery — Optimizely CMS, TypeScript and iOS
